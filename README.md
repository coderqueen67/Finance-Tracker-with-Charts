#  Personal Finance Tracker

A simple web-based Personal Finance Tracker built with **Python**, **Flask**, **HTML**, **CSS**, and **JavaScript**.

## Features

* Add transactions
* Delete transactions
* View all transactions
* Simple and responsive interface
* Flask backend with REST API
* Dynamic updates using JavaScript

## Technologies Used

* Python 3.14
* Flask
* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/coderqueen67/FinanceTrackerApp.git
```

Open the project:

```bash
cd FinanceTrackerApp
```

Install Flask:

```bash
py -m pip install flask
```

Run the application:

```bash
py app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
